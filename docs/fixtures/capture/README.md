# 抓包样本目录（本地专用）

存放真实教务会话的抓包文件（HAR / JSON / 截图）。

## 隐私红线（必读）

这些文件包含**学号、姓名、Cookie/会话令牌**，属于个人敏感数据：

- **不要提交到 GitHub**（`.gitignore` 已忽略本目录下的数据文件）
- 分析完成后可自行删除；需要长期保留的样本，必须先**脱敏**（学号/姓名/Cookie 替换为占位符）再放入 `app/src/test/resources/parser/xpu/fixtures/`
- 公开仓库里只允许出现**脱敏后的固定样本**，作为解析器的回归金样本

## 放什么

| 文件 | 说明 |
|------|------|
| `*.har` | 浏览器导出的完整会话（主材料） |
| `*.json` | 单个接口的响应样本（应急版手抄用） |
| `*.png` | 课表页面截图（用于核对解析结果） |
